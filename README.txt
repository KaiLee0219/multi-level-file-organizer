多级文件整理工具
================

本工具用于从复杂的多级目录中查找目标目录，并按可追溯规则复制其中的文件。
只复制文件，不删除、不移动、不修改源文件。

一、查找目标目录
----------------
1. 按目录层级：根目录为1级，直接子目录为2级，再下一层为3级。
2. 按文件夹名称：从根目录一直遍历到最深层，处理每一个同名文件夹。
3. 可选择只处理目标目录直属文件，或包含目标目录下的所有更深层文件。

二、输出目录结构
----------------
1. 保留相对目录结构（推荐）

源目录：
CaptureData\2026-07-31\Inspect_001\RawImages\a.bmp
CaptureData\2026-08-01\Inspect_001\RawImages\a.bmp

输出目录：
输出\2026-07-31\Inspect_001\RawImages\a.bmp
输出\2026-08-01\Inspect_001\RawImages\a.bmp

因此不同日期下的 Inspect_001 不会冲突，并且能直接看出文件来源。
“保留末尾级数”为0时保留目标目录的完整相对路径；填写2时只保留末尾两级。
如果同时提取目标目录下面的深层文件，其内部目录结构也会保留。

2. 使用上级目录组合命名

设置组合末尾2级时：
2026-07-31\Inspect_001 -> 2026-07-31__Inspect_001
2026-08-01\Inspect_001 -> 2026-08-01__Inspect_001

适合需要平铺输出、同时又要保留部分来源信息的场景。

3. 简单名称（兼容旧版）

可以使用命中目录名、向上第N级目录名或自定义名称。
该模式可能产生较多同名目录，应配合同名目录处理策略使用。

三、同名目录处理
----------------
1. 合并同一路径（推荐用于增量处理）
   多次运行时继续使用相同输出路径，SHA-256相同跳过才可稳定生效。
2. 自动编号
   同名目录生成 名称_2、名称_3，适合每个命中目录必须绝对分开的场景。

使用完整相对目录时，即使目录名同为 Inspect_001，只要日期路径不同，本身就是不同目录，
不需要通过 _2 猜测来源。

四、同名文件处理
----------------
1. 自动编号：a.bmp、a_2.bmp、a_3.bmp，不覆盖已有文件。
2. 跳过：目标位置已有同名文件时不复制。
3. 覆盖：用源文件覆盖目标同名文件。

五、内容相同则跳过（SHA-256）
--------------------------------
勾选后，程序先判断源文件和目标同名文件：
1. 文件大小不同：确定内容不同，不跳过；
2. 文件大小相同：计算双方SHA-256；
3. SHA-256完全一致：才按“内容相同”跳过；
4. SHA-256不一致：继续执行同名文件的自动编号、跳过或覆盖策略。

图片不会因为扩展名或文件名相似而被无条件跳过。
只有文件内容逐字节一致（SHA-256一致）才会被“内容相同”规则跳过。

六、预览与CSV记录
------------------
点击“预览映射与统计”，可以在复制前查看：
- 命中目录数量；
- 文件数量；
- 最终输出目录数量；
- 源目录到输出目录的真实映射；
- 当前目录与文件冲突策略。

启用CSV记录后，每次任务在输出根目录生成：
提取记录_年月日_时分秒.csv

CSV记录源文件、目标文件、复制/覆盖/编号/跳过结果、文件大小、SHA-256说明和时间。

七、推荐配置
------------
- 输出结构：保留相对目录结构，保留级数0（全部）；
- 同名目录：合并同一路径；
- 同名文件：自动编号；
- 内容相同则跳过：开启；
- CSV来源记录：开启；
- 包含目标目录下更深层文件：开启。

界面右上角“应用推荐配置”可以一键恢复以上设置。

八、打包
--------
双击 build_exe.bat，成功后生成：
dist\MultiLevelImageExtractor.exe

如果失败，请查看同目录的 build_log.txt。
